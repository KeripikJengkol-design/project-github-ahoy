# Proyek Web Sistem Informasi Absensi Kelas

Repositori ini dikembangkan untuk memenuhi tugas proyek kelompok mata kuliah pemrograman web. Proyek ini mengimplementasikan desain antarmuka responsif menggunakan kerangka kerja Bootstrap 5.

- [Syifa Nuraini/2510131120005] – Penanggung jawab Halaman Detail/Katalog & Sistem Layout CSS.
- [Jeconiah Marva Pelasula/2510131210037] – Penanggung jawab Halaman Form/Kontak & Responsivitas Media Queries/Bootstrap.

## Struktur Navigasi Halaman

Proyek ini terdiri dari beberapa halaman utama yang saling terhubung:

1. index.html (Halaman Utama / Beranda)
2. statistik.html (Halaman Statistik Kehadiran)
3. tabel.html (Halaman Rekapitulasi Tabel)
4. detail.html (Halaman Analisis & Detail)
5. form.html (Halaman Formulir Izin / Sakit)
6. kontak.html (Halaman Informasi Kontak & Tim)

## Teknologi yang di gunakan

- HTML5
- Bootstrap 5.3
